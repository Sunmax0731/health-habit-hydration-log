# Security / Privacy Checklist

        ## 方針

        健康データは医療情報として扱わず、端末内記録と明示する

        ## チェック

        - [x] 外部送信をMVP外にした。
        - [x] サンプルに実個人情報を含めない。
        - [x] 手動テストで確認すべき権限を列挙。
        - [x] release asset に手動テスト手順を添付。

        ## Android / Host 権限

        - POST_NOTIFICATIONS はリマインダーを有効にした場合のみ
- 健康連携APIはMVP外

        ## Adobe 公式参照

        - 対象ドメイン docs と created_idea metadata を優先。
