# 競合ベンチマーク

        ## 比較対象

        - MyTherapy: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- Loop Habit Tracker: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- Google Fit: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- WaterMinder: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。

        ## 採用する基準

        - 入力負荷が低い。
        - 次アクションが明確。
        - ローカルまたは閉域で検証できる。
        - docs と release evidence から状態を追える。

        ## 差別化

        水分、体調、習慣チェックを夜に振り返るAndroidログに絞り、汎用ノートや大型サービスよりも閉域アルファの検証可能性を優先します。
